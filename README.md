QR Code Generator using Python

A simple Python project that generates QR codes from user-entered URLs.

Features
Takes URL as input.
Generates a QR code.
Saves the QR code as a PNG image.
Technologies Used
Python
qrcode library
Pillow
Installation

Install the required library:

bash
pip install qrcode[pil]

How to Run
bash
python qrcode_generator.py


Enter the URL when prompted.

The QR code will be generated and saved as qrcode.png.

Output

A QR code image (qrcode.png) is generated successfully.
